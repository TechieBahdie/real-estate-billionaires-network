# Real Estate Billionaires Network — website concept

Responsive static website concept built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use StackBlitz by creating a static HTML project and uploading these four files.

## Deploy
Import the project into GitHub and deploy the repository on Vercel. No build command is required; set the output directory to `.` if prompted.

## Important content notes
- This is a demonstration concept, not the company's official website.
- The catalogue has 13 unique WhatsApp product links; the duplicate link supplied as items 1 and 3 is included once.
- Property cards are clearly numbered catalogue placeholders. Their photos are illustrative stock imagery, not confirmed listings from the company.
- No prices, property names, addresses, titles, accreditation, testimonials or investment returns have been invented.
- The contact form opens WhatsApp with a prefilled message. It does not store submissions.
- Confirm the preferred legal/trading name and all contact details with the business before public launch.
